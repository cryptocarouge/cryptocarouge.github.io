ABOUT THE WORK

Real systems.
Clear boundaries.

I am Leandro Carouge. I build practical automation systems around real problems, mostly with n8n, APIs, JavaScript and LLMs. The common theme is simple: keep control logic deterministic, keep state explicit, and use AI only where it actually adds value.

HOW I WORK

Automation first. AI with a job description.

01
Deterministic before generative
Routing, validation, state transitions and persistence belong in normal workflow logic when possible.
02
Explicit state
The system should know what happened, what is pending and what has already been processed.
03
Verification before action
External data is normalized and checked before it is allowed to trigger downstream behaviour.
04
Operational resilience
Retries, fallbacks, health checks and degradation alerts are part of the design.
05
Privacy by design
Public repositories explain the engineering without publishing production credentials, private identifiers, personal data or sensitive logic.
WHY THE PUBLIC REPOS LOOK DIFFERENT

The portfolio is intentionally not a production backup.

The systems shown here are real projects, but the public repositories are curated architecture editions. They expose the ideas, structure, technologies and engineering decisions while keeping production configuration private.

Public

Architecture, technology choices, engineering rationale, case studies, safe diagrams and selected implementation concepts.

Private

Credentials, personal data, internal endpoints, full proprietary prompts, live identifiers, production parameters and workflow exports.
