THE PROBLEM

Publishing automatically without becoming automated noise.

A single prompt that researches, writes and publishes is hard to trust. This system first builds factual context, then generates, validates, publishes, verifies the result and only afterwards mutates memory.

ENGINEERING DECISIONS

What matters under the hood.

✓
Facts before prose
External sources are collected and converted into bounded context before the model writes.
✓
Deterministic controls around AI
Routing, anti-spam, publication verification and state updates remain normal workflow logic.
✓
Memory only after confirmation
A failed publication is never remembered as if it were successfully posted.
✓
Manual does not bypass safety
Telegram-triggered manual publishing still goes through the same downstream validation and verification.
PUBLIC / PRIVATE BOUNDARY

Proof without secrets.

The public version excludes OpenAI keys, X OAuth credentials, Telegram identifiers, private style prompts, account-specific settings, internal memory and the production workflow JSON.
TAKEAWAY

Facts first. Generation second. Confirmation before state.

The reusable pattern is an AI publishing system where the model creates content, but the workflow remains responsible for truth inputs, control flow, verification and state.
