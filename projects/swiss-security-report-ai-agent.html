A privacy-first assistant that turns operational voice or text input into structured professional incident reports while keeping a strict factual boundary.

THE PROBLEM

Improve the writing without inventing the incident.

Operational notes are often captured quickly, but the final report must remain factual. The model is used to structure and express supplied information, not to fill in missing names, times, actions or outcomes.

ENGINEERING DECISIONS

What matters under the hood.

✓
Facts are the source of truth
Missing details remain missing rather than being inferred.
✓
Routing stays deterministic
Voice detection, callbacks, session restoration and output routing are normal workflow logic.
✓
AI has a narrow job
The model handles transcription, language interpretation and report drafting.
✓
Privacy boundary is explicit
The public project contains no resident/client data or employer-specific operating procedures.
PUBLIC / PRIVATE BOUNDARY

Proof without secrets.

The public version excludes personal/resident information, employer procedures, private webhook URLs, credentials, chat IDs, production prompts and the production workflow JSON.
TAKEAWAY

Use AI for language capability, not for factual invention.

The core pattern is LLM-assisted professional writing under a strict operational boundary, with deterministic workflow logic controlling the process.
