PUBLIC SECURITY POSTURE

Show the engineering.
Keep production private.

The public portfolio is deliberately separated from production systems. Architecture and engineering decisions are public; secrets, personal data, live identifiers and sensitive implementation details are not.

AUTOMATED GUARDRAILS

Every public project gets checked twice.

01
GitHub Secret Scanning + Push Protection
Provider-recognized secrets are checked by GitHub before and after they reach the public repository.
02
Custom public-safety CI
A repository workflow scans public text files for key/token patterns, private webhook URLs, live Google document URLs, n8n credential objects, private infrastructure references, private personal references, email addresses and Swiss phone numbers.
03
No matched value is echoed into CI logs
If the custom scan fails, it reports only the file and match category so the safety mechanism does not create a second leak.
04
Production workflows stay private
Public repositories are documentation and architecture editions, not production exports.
PUBLIC BOUNDARY

What never belongs in the portfolio.

Secrets

API keys, tokens, passwords, OAuth secrets, private keys and credential objects.

Identifiers

Private chat IDs, live document IDs, internal webhook URLs and private infrastructure endpoints.

Personal data

Client, resident, family or other non-public personal information.

Proprietary production logic

Exact sensitive parameters, full production prompts, execution rules and live workflow exports.

SITE PRIVACY

No analytics. No tracking scripts.

This portfolio is a static GitHub Pages site. It does not include analytics, advertising pixels or third-party tracking scripts.

PRIVACY FIRST

Portfolio rule

Public visibility is used to demonstrate engineering, not to make production reproducible.

Repository policy

Public project repositories explicitly state that no open-source license is granted unless the owner says otherwise.

Current model

Static public site + curated public repos + private production workflows.
