# Security and Privacy

This repository powers the public CryptoCarouge portfolio site.

The site must contain only information intentionally prepared for public presentation.

## Never publish here

- API keys, tokens, passwords or private keys
- n8n credential objects or credential identifiers
- Private webhook URLs or internal hostnames
- Telegram bot tokens or private chat IDs
- Live Google document/spreadsheet identifiers
- Personal, client or resident information
- Employer-specific operational procedures
- Production workflow exports
- Proprietary decision parameters or private prompts

## Scope

Architecture, technologies, engineering decisions and public case-study links are allowed. Production systems remain private.
